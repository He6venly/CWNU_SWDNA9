# 챙기고 로고·아이콘 제작 목록

## 제작 기준

- 권장 형식: SVG. PNG 사용 시 투명 배경 256px 이상
- 기본 아이콘: 24×24 기준, 둥근 선, 1.8~2px 두께, 단색 또는 2색 이하
- 로고: 가로형보다 정사각 심볼 우선. 헤더 표시 영역 48×48px, 모바일 40×40px
- 대한항공 로고·태극 문양을 복제하지 않고 챙기고 고유 형태 사용

## 우선 제작

| 파일명 제안 | 용도 | 권장 색감 |
| --- | --- | --- |
| `brand-logo.svg` | 헤더·파비콘용 챙기고 심볼 | 네이비·스카이블루 |
| `icon-flight.svg` | 항공사·노선 선택 | 파랑 |
| `icon-photo-scan.svg` | 사진 등록·AI 분석 | 청록·하늘색 |
| `icon-quick-check.svg` | 사진 없이 빠른 확인 | 보라 |
| `icon-verify.svg` | 물품 정보·출처 확인 | 초록 |
| `icon-trip-album.svg` | 여행 앨범·준비 체크 | 주황 |
| `icon-catalog.svg` | 개인 도감 | 골드 |
| `quick-power-bank.svg` | Quick Check 보조배터리 | 초록 |
| `quick-hair-iron.svg` | Quick Check 고데기 | 핑크·자주 |
| `quick-liquid.svg` | Quick Check 액체·젤류 | 파랑 |

## 결과·보조 기능

| 파일명 제안 | 용도 |
| --- | --- |
| `verdict-allowed.svg` | 반입 가능 |
| `verdict-conditional.svg` | 조건부 가능 |
| `verdict-prohibited.svg` | 반입 불가 |
| `verdict-needs-info.svg` | 추가 정보 필요 |
| `icon-carry-on.svg` | 기내 휴대 결과 |
| `icon-checked-baggage.svg` | 위탁 수하물 결과 |
| `icon-label.svg` | 라벨 사진 보완 |
| `icon-product-search.svg` | 모델명 제품 조회 |
| `icon-checklist.svg` | 출발 전 준비 체크 |
| `icon-copy-list.svg` | 다음 여행에 목록 복사 |
| `icon-staff-card.svg` | 직원용 한영 카드 |

현재는 동일 위치에 색상형 인라인 SVG 아이콘을 적용함. 최종 파일 수령 후 위 이름으로 교체하면 됨.

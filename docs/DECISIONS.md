- 사용자 추가 요청: 사진 주 흐름 유지, 수동 빠른 확인·구조화 조건·개인 도감의 직원 모드 흡수. 이번 변경은 테스트를 보류하고 구현 우선. 상세 결과는 요청 옵션으로 제공해 기존 호출 유지. 도감은 독립 IndexedDB 예시로 분리해 별도 프론트 저장소 보존
- 사용자 승인으로 로컬 Gemini 실호출 활성화. 실행 환경 gemini-2.5-flash에서 인식·제품 조회 응답 확인. 검색+강제 JSON 조합 거절과 인용 누락에 대응해 조회만 검색→구조화 최대 2회로 분리(전체 20초·자동 재시도 없음). URL은 검색 메타데이터에서 서버가 연결하고 공칭전압만 수집. 추가 호출 비용은 조회에 한정. 전체 테스트·제품 사진·배포 검증은 별도.

- 사용자 결정: Netlify 배포 대신 로컬 시연 영상으로 진행. 여행별 짐 앨범과 인식 결과 재사용을 추가. 앨범은 브라우저에 저장하고 복사한 목록은 재확인·재판정한다.

## 라벨 인식 출처 누락 수정
- 실사진 진단에서 field source mismatch 재현. 제공자 JSON 스키마 단순화가 partialRecord의 additionalProperties 값 구조를 제거한 문제 확인.
- enum 키를 명시적 속성으로 변환. 인식 제공자 응답은 7개 출처 키를 필수·nullable로 수신하고 공용 계약에서는 null 출처만 생략. 사양·출처를 임의 보충하지 않고 기존 의미 검증 유지.
- 제공된 보조배터리 사진으로 수정 후 recognize 성공. 원문·사진 로그 및 서버 저장 없이 진단. 테스트 163개·빌드 통과. npm run check는 기존 image.ts·TravelAlbum.tsx 린트 경고 3건으로 중단. 브라우저 재검증 별도.

## 사용자 프론트 통합·로컬 검증

- 사용자 프론트에 항목별 라벨 보완, 동일 인식 요청 캐시, Web Worker 전처리, 여행 앨범 저장·복사를 연결. 라벨 결과는 선택 항목의 빈 필드만 보완하고 사용자 값·수량을 보존하며 재확인을 요구.
- 작은 픽셀 샘플의 평균 밝기·경계 변화량으로 어두움·과노출·흐림을 전송 전에 경고하되 차단하지 않음. 라벨은 고주파 영역이 충분히 모인 경우만 여백을 보수적으로 자동 크롭하고 1800px·높은 JPEG 품질부터 압축해 글자 손실을 줄임.
- 캐시는 사진·분석 입력·연결 상태 범위가 같을 때만 5분간 재사용. 상태 새로 확인 시 비워 모델·제공자 변경 결과를 재사용하지 않음.
- 로컬 연결 실패 원인은 실행 프로세스 부재 또는 응답하지 않는 이전 Vite 프로세스였음. 사용자 프론트가 공유 Worker를 읽을 때 Vite 허용 경로 밖 403도 확인해 `server.fs.allow`에 check/contract 범위를 명시.
- 검증: 5173 API, 5174 화면·프록시 HTTP 200. 사진 선택·Worker 전처리·미리보기, 수동 판정, 도감, 직원 화면, 앨범 저장·새로고침·목록 복사, 모바일 가로 넘침 없음 확인. Gemini 실인식은 제공자 응답 실패로 완료하지 못했으며 입력 보존·재시도 안내까지만 확인.

- 사용자 피드백으로 전체 로고 헤더와 별도 배경 패널 적용을 철회. 헤더는 기존 `brand-logo.svg` 심볼과 텍스트 조합으로 복원하고 자산 외부의 배경색·테두리는 추가하지 않음.
- 사용자 의도 재확인: 헤더는 전체 `logo.png`를 사용하되 PNG의 투명 배경을 그대로 노출. 별도 패널·배경색·테두리는 사용하지 않고 어두운 헤더에서 가장자리만 유지하는 최소 드롭섀도만 적용.
- 여행 경로는 대한민국을 기본 출발국으로 두고 한국인이 자주 찾는 주요 해외 여행국 20곳만 선택지로 제공. 출발·목적 국가 교환으로 귀국편도 입력하되, 현 규정 엔진 범위 밖인 해외 출발은 현지 규정 추가 확인이 필요한 참고 판정으로 명시.
- 목적 국가는 국내선도 기본값을 두지 않으며 사용자가 직접 선택. 목적 국가가 비어 있으면 상단 탐색·물품 등록 버튼·직접 URL 진입 모두 여행 홈에서 차단하고 선택 위치를 오류 표시. 목적지가 정해진 뒤 비어 있는 출발국·항공사·출발일만 대한민국·대한항공·사용자 현지 오늘 날짜로 보완. 큰 경로 선택 표시와 펼침 선택 목록의 글꼴 크기를 분리해 목록이 함께 확대되지 않게 함.
- 앞선 버전이 국내선 목적지를 대한민국으로 자동 저장한 기존 IndexedDB 기록은 1회 마이그레이션으로 목적지만 비움. 이후 사용자가 대한민국을 직접 다시 선택한 값은 유지.
- 빠른 규정 확인은 품목 검색·사진 인식을 먼저 두고, 품목을 확인한 뒤 항공사를 선택하면 즉시 공통 예비 안내를 표시. 26개 품목과 별칭을 6개 기존 판정 분류에 연결해 문자 검색은 외부 호출 없이 반응하며, 사진 버튼은 단일 근접 사진을 기존 Gemini 인식 API로 분석하고 시연 응답이면 명시.
- CanFly 공개 품목 목록 페이지에서 확인한 10개 분류 98개 품목명을 한국어 검색 데이터로 추가. 대만→일본용 판정 문구는 복사하지 않고, 우리 6개 분류와 위험·검역·세관별 보수적 예비 안내에 연결. 기존 한국어 보조 품목 2개는 추가 유지.
- 패널 아이콘은 46px 둥근 배지, 검색·결과용 아이콘은 36px로 통일하고 제목 묶음의 수직 중앙에 정렬. 광범위한 `span` 스타일이 아이콘 래퍼까지 덮던 충돌을 전용 텍스트 클래스로 분리하고 검색·전자기기·점화용품·일반 품목 아이콘을 보강.
- 품목 검색의 100개 항목은 공용 분류 아이콘 대신 품목별 그림문자 아이콘을 사용. 검색 결과·선택 단계·즉시 결과에서 같은 아이콘을 재사용하고, AI가 새 이름을 반환한 경우에만 분류별 대체 아이콘을 사용.
- 국가 선택은 노선 토글보다 우선하며 대한민국↔대한민국은 국내선, 한쪽이라도 해외면 국제선으로 자동 전환. 국내선 상태에서도 해외 국가 선택을 막지 않아 노선 토글을 먼저 조작해야 했던 문제를 제거.
- 물품 등록의 기존 3개 직접 추가 버튼은 홈의 100개 품목 검색·사진 인식·항공사별 빠른 규정 확인 컴포넌트로 통합. 확인한 품목은 같은 화면에서 상세 입력 목록에 추가.
- 같은 검색 컴포넌트를 재사용하되 홈은 `급할 때 빠른 규정 확인`, 물품 등록은 목적에 맞게 `품목 빠른 검색·추가`로 제목을 구분.
- 물품 카드의 제품 조회와 제외 동작은 구분선 아래 우측 정렬 작업 행으로 묶고, 모바일에서는 전체 폭 세로 버튼으로 전환해 버튼이 붙거나 잘리지 않게 함.

- 인식·제품 조회 모델을 `gemini-3.6-flash`로 통일. 3.8은 실제 호출에서 503 과부하와 429 요청 제한, 3.7은 3.8 자동 라우팅으로 시간 초과를 확인함.
- 같은 키의 3.6 Interactions 호출은 200 응답을 확인. 이미지 입력·구조화 출력·Google 검색을 지원하는 안정 버전으로 선택함.

## 2026-10-31 Gemini 인식·조회 모델 분리

- 사진 인식·검색 결과 구조화는 `gemini-3.6-flash`, 제품 조회의 Google 검색은 `gemini-2.5-flash`로 분리함.
- 3.x 일반 생성·사진 인식은 가능하지만 무료 API의 Google 검색이 429로 차단됨. 2.5 검색 Grounding은 무료로 제공되나 현재 키는 20회/일 모델 한도를 소진해 다음 초기화 후 실조회 재검증이 필요함.

## 2026-10-31 Tavily 제품 검색 전환

- Gemini 무료 검색 한도와 신규 계정의 2.5 접근 제한을 피하기 위해 제품 웹 검색을 Tavily로 분리함.
- Tavily 기본 검색 1회 결과에서 정확한 모델명이 확인된 출처만 사용하고, 명시된 용량·공칭전압만 서버가 보수적으로 추출함. 제품 조회에는 Gemini를 추가 호출하지 않으며 사진·검색 원문·키를 저장하거나 로그로 남기지 않음. 최종 반입 판정은 기존 순수 규정 엔진을 유지함.

## 2026-10-31 16개 항공사 규정 적용

- 사용자 결정으로 대한항공 단일 승인 범위를 16개 지원 항공사로 확대한다.
- 대한항공 엔진 결과를 이름만 바꿔 재사용하지 않고 항공사별 프로필·공식 출처·규정 버전을 적용한다.
- 에어로케이·파라타항공은 세부 공식 제한 페이지를 확인하지 못해 국토교통부 한국 항공사 공통 지침을 보수적으로 적용하고 화면에 출처를 공개한다.
- 제품 조회는 Google Search API로 표시하지 않는다. 현재 구현과 기능 상태는 Tavily로 명시한다.

## 2026-10-31 비용 절감형 인식·검색 분리

- Gemini는 사진·라벨 인식에만 사용하고 동일 요청의 성공 결과를 실행 중 30분간 재사용한다.
- 라벨의 Wh 또는 mAh·공칭전압을 사용자 확인 후 순수 계산하며 제품 검색을 필수 단계로 두지 않는다.
- Tavily는 모델명이 확인됐지만 사양이 부족할 때만 사용자가 선택 실행한다. 실패·한도 초과는 빈 후보 정상 응답으로 처리해 수동 입력을 계속한다.
- 외부 호출은 자동 재시도하지 않는다.

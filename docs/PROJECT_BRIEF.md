# 아이디어 기획지

상태: 사용자 요구로 여행 물품 인식·제품 조회·항공사 규정 대조 서비스 확정. 임시 제목은 여행 짐 반입 확인. Netlify 배포 필수. 빈 항목은 미정.

## 문제 정의

- 한 문장 아이디어: 짐을 넣기 전 사진에서 물품·제품 정보를 확인하고 항공사별 기내/위탁 결과를 참고하는 서비스
- 대상 사용자: 항공 여행을 준비하는 여행자
- 사용자가 겪는 구체적 상황과 문제: 제품별 반입 조건 확인과 직원에게 보여줄 제품 정보 정리 필요

## 최소 구현 범위

- 사용자가 입력하는 정보: 항공사, 물품 사진, 확인·수정한 모델명·용량 등 제품 정보
- 사진 입력 기본 방식: 이미 찍어 둔 사진을 사진 보관함·파일에서 선택해 등록. 앱 내 촬영·카메라 권한은 필수 아님. 선택 후 미리보기·품질 확인·분석 요청
- 핵심 처리: 사진 인식 → 제품 정보 조회 → 사용자 확인 → 항공사 규정과 대조
- 사진 분석 모드: 전체 짐 overview / 개별 물품 detail. 개별은 label/estimate. 2.0 계약·시연 API에 반영, 실제 인식은 미연결. 1.0은 별도 유지
- 결과 화면에서 얻는 가치: 기내/위탁 각각 결과·설명·권장 조치·직원용 참고 요약
- 반드시 작동할 기능: backend API·contract·최소 체크 화면. 사용자 UI/UX·티켓 디자인·IndexedDB 개인 도감은 프론트 담당
- 시간 여유가 있을 때 추가할 기능:
- 이번 제작에서 제외할 기능: 예약·일정 추천·긴급 신고·로그인·서버 도감 저장

## 구현 조건

- 사용할 데이터와 확보 방법: 인식·제품 조회는 시연. 대한항공 공식 규정은 검수한 JSON·순수 알고리즘으로 제공. 범위·출처·기한은 docs/RULE_ENGINE.md
- AI 역할: Gemini로 사진·제품 라벨 인식·제품 정보 검색. 불명확한 값은 null, 추가 입력 요청. 최종 규정 판정은 순수 알고리즘으로 확정
- 실제 규정 대상·범위: 대한항공 직접 운항편, 한국 국내선·한국 출발 국제선(departureCountry=KR), 여행자 1명, 6개 분류. 사용자 확인할 추가정보 확장. 해외 출발·공동운항·환승·목적지 세관/검역은 별도 확인
- 서버·DB·로그인 필요 여부: Netlify Functions, 기본 무상태. 도감은 프론트 로컬 저장, 서버 사진 저장 없음
- 외부 API 비용·제한:
- 데이터 보관·개인정보 처리: 사진·개인정보 로그 금지. Gemini 실연결 시 외부 전송·처리 정책 확인 필요
- 배포 방식: Netlify 필수 — React + Vite 체크 화면(`dist/check/`) + Functions(`/api/*`). 실제 배포 미수행
- 지원 환경: PC 웹과 모바일 브라우저 모두 필수. 기존 사진 선택·업로드·입력·결과 조회를 같은 API로 지원하고 실제 기기 검증 필요

## 빠른 확인·결과 표시 확장 (구현 우선, 검증 보류)

- ItemInfo에 manual 식별과 선택 imageId, 사진 없는 카드 허용. 인식 응답의 기존 라벨/추정 구조는 유지
- 선택 요청 resultFormat=detailed와 결과 presentation: 조건·추가 정보·근거·승인/기내 사용 상태·영문 요약. 기존 응답은 옵션 생략 시 유지
- 수동 입력 헬퍼·조건부 목업·브라우저 도감 저장 모듈·직원 화면 예시 제공. 신규 의존성·유료 호출 없음
